IMPORT THE WEBSITE LIST INTO ESET BY HAND
========================================

Program 2 builds ONE combined import file: eset-blocked-urls.txt.
BUILD opens the list in Notepad, opens its folder with the file selected,
and copies the FULL FILE PATH
(not the website entries) to the clipboard, then opens ESET and this guide.
If the clipboard is unavailable, the full path is printed in the program.
Use "Open the list folder" to find the file again without rebuilding it.

TeamViewer, AnyDesk, Splashtop and RustDesk are UNTICKED by default in both
programs. Unticked means allowed. Tick a tool before BUILD to include its
websites. Program 1 is separate: its choices control the Windows program
block, and it displays installed choices if a policy already exists.

REVIEW BEFORE IMPORT: the combined file includes domains used legitimately
for AV updates, SaaS and VPN services (Sophos, GoTo, Tailscale, Ninite, etc.).
Review optional-tier rows in url-review.csv and remove anything the client
needs from eset-blocked-urls.txt. Shared platform root filters remain active.

IN ESET (wording may differ by version):
  1. Press F5 to open Advanced setup.
  2. Protections -> Web access protection -> URL list management.
  3. Next to Address list, click Edit.
  4. Add a NEW address list of type Blocked, named RMM scam block (lolrmm).
     Leave List active ticked. If unavailable, edit List of blocked addresses.
  5. Inside that list, choose Import.
  6. Paste the copied FILE PATH into the File name box (Ctrl+V), then Open.
     If clipboard copy failed, browse to the file in the folder that opened.
     Do NOT paste the path into "Enter multiple values": it is not a website.
  7. OK on every window, then OK in Advanced setup to save.

TEST: choose a website actually present in eset-blocked-urls.txt and visit
it in a browser. ESET should block it. AnyDesk is NOT a valid default test:
it is allowed unless its checkbox was ticked before building the list.

UNDO: F5 -> Protections -> Web access protection -> URL list management ->
Address list -> Edit. Select RMM scam block (lolrmm) and Remove, or untick
List active. OK -> OK. Do not delete unrelated pre-existing blocked entries.

This program does NOT import into ESET automatically or verify the import.
It does NOT apply the Windows program block. Use 1\START-HERE.bat for that.
The two programs have independent checkboxes; set each one as required.
