MUST BE DONE BY HAND BY A TECHNICIAN  -  PUT THE BLOCK BACK OUT OF ESET
=====================================================================

THIS STEP CANNOT BE AUTOMATED. The tool cannot remove the ESET website list for
you: ESET's URL list is a GUI import/paste with no scriptable interface, and this
project deliberately does not guess at ESET's configuration XML.
EVERY ACTION BELOW IS DONE BY HAND.

Run-Revert.bat has already:
  - backed up the current state into backups\<timestamp>\
  - REMOVED the Windows App Control block (the programs)
  - opened ESET and this file

The website list is the one piece a script cannot do, because ESET's URL list is
a UI import/paste. It takes about a minute.


1. In ESET, press F5  (Advanced setup)
2. Click  Protections  ->  Web access protection
3. Open  URL list management, then next to  Address list  click  Edit


IF YOU MADE OUR OWN LIST  (named "RMM scam block (lolrmm)")
   - select it in the Address list window
   - click  Remove            <- one click, done
   - OR untick "List active" to switch it off but keep it for later
   - OK -> OK

IF INSTEAD YOU PASTED INTO ESET'S OWN "List of blocked addresses"
   - select  "List of blocked addresses"  ->  Edit
   - click the FIRST entry, then Shift+click the LAST
   - click  Remove
   - OK -> OK
   ! That list may have held YOUR OWN blocked sites before we added ours -
     check before you remove everything. If it did, remove only our entries.
     The full set we added is saved in this folder under
     backups\<timestamp>\eset-lists\  (eset-blocked-urls.txt), so you can
     compare and see exactly which lines were ours.


TURN OFF THE BACKSTOP TOO  (optional)
   In Advanced setup, type  unsafe  in the search box, and switch OFF
   "Enable detection of potentially unsafe applications".
   Leave it ON if you want ESET to keep flagging remote tools as they are saved.
   If it flagged Splashtop or anything you use on purpose, open the detection and
   choose "Create exclusion" instead of turning the whole thing off.


CHECK IT WORKED
   Open a browser and go to  anydesk.com
   -> the ESET "page blocked" message should be GONE.


PUT THE BLOCK BACK LATER
   Run-Revert.bat -Restore      (pick the dated backup to restore)
   ... then re-add the website list in ESET using the guide in the main kit,
   or the saved list in backups\<timestamp>\eset-lists\.

THIS ENTIRE FILE IS A MANUAL PROCEDURE. If it was not done by a technician, the
ESET website part of the block is still in place.
